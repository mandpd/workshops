THE X-RAY

The anatomy of a TUI agent

An agent isn't a single thing. It's a loop running inside a context budget, shaped by files in your repo, tools you've wired up, and instructions you've written. Here's what's really inside when you run one.

In the repo (or workspace)
my-project/
├── AGENTS.md always
Agent-agnostic project memory
├── CLAUDE.md always
Claude-specific memory (optional)
└── .claude/ (or .agents/)
    ├── commands/ on invoke
User-invoked shortcuts
    ├── skills/ on demand
Lazily loaded procedural knowledge
    └── settings.json session
Modes, MCP servers, tool config
